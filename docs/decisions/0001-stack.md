# Prototype stack

- Node.js 26.13.1, the current Active LTS line at setup. [Node.js releases](https://nodejs.org/en/about/previous-releases)
- Vanilla TypeScript from the official create-vite template. The dependency lockfile records Vite, TypeScript, Oxlint and Playwright versions.
- Static DOM and CSS rendering to provide native buttons, keyboard navigation and responsive sizing. Browser Web Audio synthesizes effects locally.
- Node's built-in test runner checks deterministic logic and the level solver. Playwright covers the public browser entry point. The versioned save lives in the browser.
