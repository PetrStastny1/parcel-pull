# Parcel Pull

The [approved board](approved/desktop.png) uses the brief's blue, ochre and purple parcel colors with circle, triangle and square symbols. Docks display the same symbols. The board and controls use the same tiles, system typography and focus ring in both color schemes. The moves panel sits beside the board on desktop and underneath it in portrait.
